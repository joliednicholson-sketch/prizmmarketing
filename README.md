# Prizm Marketing website

Static website for **prizmmarketing.org**. It's plain HTML and CSS, so there's no build step.

## Files

- `index.html`: page content
- `styles.css`: styling
- `assets/`: logo and portfolio screenshots
- `CNAME`: tells GitHub Pages to serve the site at prizmmarketing.org
- `.github/workflows/pages.yml`: deploys to GitHub Pages on every push to `main`
